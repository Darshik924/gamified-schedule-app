⚡ CTRL ALT ELITE: The Wizarding Quest Board
A gamified productivity system inspired by the Harry Potter universe, built for the Hacksagon Hackathon at IIT Indore.
<hr>
📖 Overview
Traditional to-do lists are boring and often fail to motivate long-term habit building. The Wizarding Quest Board transforms mundane academic and personal tasks into "Magical Quests." By completing tasks, users earn XP and Galleons (coins), allowing them to level up and unlock iconic characters from the Wizarding World.
<hr>
🛠️ Tech Stack
<ul>
<li>Frontend: HTML5, JavaScript</li>
<li>Styling: Tailwind CSS (for modern, responsive UI)</li>
<li>Theme: RPG-Style / Harry Potter Universe</li>
<li>Data Persistence: Window.localStorage (Ensures your quests, XP, and unlocked characters are saved even after closing the browser)</li>
</ul>
<hr>
✨ Features
1. Gamified Kanban System: Move tasks from "To-Do" to "In Progress" and "Completed."</br>
2. XP & Leveling: Earn Experience Points (XP) for every task completed. Level up to increase your wizarding rank!</br>
3. Currency & Shop: Earn coins upon leveling up. Visit the Purchase Window to buy new character cards.</br>
4. Customizable Profiles: Initially unlocked with Harry Potter, users can "purchase" and set Ron, Dobby, Dumbledore and many more as their active profile avatar.</br>
5. Deadline Tracking: Add timelines to your tasks to ensure you don't miss your "potions homework."</br>
6. Penalties: User will loose XP points on missing the deadline.</br>
